## 📌 About This Repository
This repository contains my personal solutions to various LeetCode challenges, encompassing Data Structures, Algorithms (DSA), and Database querying. It serves as a continuous log of algorithmic problem-solving and optimization practices.

* **Languages Used:** Primarily Python for core logic and PostgreSQL for database problems.
* **Structure:** Each directory corresponds to a specific LeetCode problem, containing the solution code and occasionally the problem description.

## ⚙️ Automation Workflow
This repository is maintained using a seamless automated CI/CD pipeline:
1. **Submission:** Solutions are synced directly from the browser using the LeetSync extension.
2. **GitHub Actions:** Every new push triggers a custom `.yml` workflow.
3. **Auto-Generation:** A Python script scans the directory structure and dynamically rebuilds the solutions table below.
